# idealista iOS Challenge
Este proyecto es una prueba técnica desarrollada como parte de un proceso de selección para un puesto de iOS Developer en Idealista.


## 🚀 Funcionalidades
- Exploración de Anuncios: Busca y navega por una lista de anuncios inmobiliarios.
- Detalles del Anuncio: Consulta información detallada como precio, ubicación, características y más.
- Gestión de Favoritos: Añade y elimina anuncios de tu lista de favoritos.

## 🛠️ Tecnologías y Herramientas
- Swift: Lenguaje principal del desarrollo.
- SwiftUI: Para el diseño de interfaces de usuario modernas y declarativas.
- Core Data: Persistencia de datos local.
- DTOs: Mapeo estructurado de datos entre capas.
- XCTest: Para pruebas unitarias.
- SwiftLint: Aseguramiento de clean code mediante reglas de estilo.
